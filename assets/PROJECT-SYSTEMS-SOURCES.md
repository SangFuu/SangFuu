# Project Systems Map — sources

The project map is based on the current public source files in these repositories:

- `SangFuu/open-source-security-checker`: CLI dispatch, password rules, `HTMLParser`, terminal findings.
- `SangFuu/logo-interpreter`: lexer, parser, AST, environment and terminal turtle.
- `SangFuu/tower-defense`: SDL2 events/rendering, simulation, 2D board, linked lists and text/binary saves.

The human-drawn figure is **Reading Side** from **Open Doodles**, created by Pablo Stanley. Open Doodles is published under **CC0** and may be copied, edited and remixed. The original accent and ink colors were adapted to the profile palette.

Official sources:

- https://www.opendoodles.com/about
- https://www.pablostanley.com/work/open-doodles
- https://opendoodles.s3-us-west-1.amazonaws.com/reading-side.svg

The information layout and technical diagrams were composed specifically for the SangFuu profile. No image generator was used.
