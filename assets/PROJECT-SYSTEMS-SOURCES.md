# Project Systems Map — sources

The project map is based on the current public source files in these repositories:

- `SangFuu/open-source-security-checker`: CLI dispatch, password rules, `HTMLParser`, terminal findings.
- `SangFuu/logo-interpreter`: lexer, parser, AST, environment and terminal turtle.
- `SangFuu/tower-defense`: SDL2 events/rendering, simulation, 2D board, linked lists and text/binary saves.

The three header marks are derived from the projects themselves: a terminal audit, a Logo turtle path, and a Tower Defense grid. The information layout and technical diagrams were composed specifically for the SangFuu profile. No image generator or decorative stock illustration was used.
